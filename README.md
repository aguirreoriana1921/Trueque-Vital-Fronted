# TruequeVital - Frontend

Aplicación web desarrollada en React con Vite para la gestión e intercambio colaborativo de productos y servicios.

## 🚀 Stack Tecnológico
- **Frontend:** React + Vite
- **Entorno de Ejecución:** Node.js
- **Control de Versiones:** Git & GitHub

## 🛠️ Requisitos Previos
- Node.js (versión 18 o superior)
- npm o yarn

## 🔧 Instalación y Ejecución Local

1. **Clonar el repositorio:**
   git clone https://github.com/TuUsuario/Trueque-Vital-Fronted.git
   cd Trueque-Vital-Fronted
   npm install
   npm run dev
